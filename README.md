# Clock, Stopwatch, Timer, and Alarm

A lightweight browser-based time utility built with HTML, CSS, and vanilla JavaScript. It displays the current date and time and includes a stopwatch, countdown timer, and alarm clock.

## Features

- Live local date and time display
- Stopwatch with start, stop, and reset controls
- Countdown timer configured in seconds
- Alarm clock configured with a time of day
- Responsive layout for smaller screens

## Run

Open `index.html` in a modern web browser. No installation or build step is required.

## Usage

- Use the **Start**, **Stop**, and **Reset** buttons to control the stopwatch.
- Enter a duration in seconds and select **Start** to begin the countdown.
- Choose a time and select **Set Alarm**. Select **Stop Alarm** to silence or cancel it.

Alarm audio is loaded from an external URL, so an internet connection may be needed to hear it.
